# おそうじWHITE Webサイト

静的サイト（HTML / CSS / JS、ビルド不要）。GitHub Pages（main ブランチ / ルート）で公開。

## 構成
- `index.html` … 全セクション（HEADER → 01 FV → 02 お悩み → 03 WHITEなら → 04 サービス → 05 選ばれる理由 → 06 料金 → 07 ご依頼の流れ → 08 Q&A / 09 対応エリア → 10 会社・スタッフ紹介 → 11 CTA → FOOTER）
- `css/style.css` … CSS変数・共通パーツ（container / sec-grid / rail / btn / card）・セクション別スタイル
  - PC 1200px〜 / タブレット 768〜1199px / スマホ 〜767px（料金カード・流れのみ 999px でも段組み変更）
- `js/main.js` … ハンバーガーメニュー、ヘッダーの影
- `images/` … 画像（写真はすべて仮画像 SVG）
- `logo.png` … 支給ロゴ原本（`images/logo*.png` はここから書き出し）
